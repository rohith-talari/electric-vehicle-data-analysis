# 🏺 Artifacts Directory

This directory holds serialized analytical outputs and matrices generated by `main.py --stats`:

- **`statistical_summary.csv`**: Consolidates mean, median, mode, variance, standard deviation, range, IQR, skewness, kurtosis, and Shapiro-Wilk normality determinations across all numerical attributes.
- **`covariance_matrix.csv`**: Pairwise sample covariance matrix.
- **`correlation_matrix.csv`**: Pairwise Pearson correlation matrix ($r \in [-1, +1]$).
