# 📑 Reports & Visualizations

This directory contains academic deliverables, assessment documents, and generated high-resolution plots:

- **`EV_Data_Analysis_Project_Report.pdf`**: 10-page formal laboratory term-work report covering problem formulation, library tutorials, data dictionary, preprocessing methodology, statistical measures, graphical interpretations, and viva-voce assessments.
- **`figures/`**: High-resolution figures (DPI 150):
  - `fig1_univariate_distributions.png`: Histograms with KDE and boxplots.
  - `fig2_range_vs_battery_scatter.png`: Scatter plot with global linear regression fit.
  - `fig3_correlation_heatmap.png`: Pearson correlation matrix heatmap.
  - `fig4_probability_distribution_qq.png`: Empirical density vs Gaussian fit and Q-Q normality plot.
  - `fig5_manufacturer_benchmarks.png`: Top 8 EV manufacturers by range and powertrain share.
  - `fig6_energy_vs_acceleration.png`: Energy consumption vs acceleration colored by top speed.
